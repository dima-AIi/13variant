# История изменений

## 0.9.0 — альфа-версия

- Шесть модулей решения .NET 10 с запуском окна входа из Visual Studio.
- SQLite с миграциями, семью стартовыми заказами и четырьмя учебными учётными записями.
- Контроллеры заказов, заказчиков и пользователей, Swagger и сценарии HTTP.
- Доступ по JWT для администратора, менеджера и сборщика. Сборщик видит свои заказы.
- Поиск, фильтры, статистика, отчёт ошибок CSV и выгрузка в CSV, JSON, XML.
- Журнал API на Serilog и ежедневный журнал WPF с хранением 14 дней.
