# История изменений

## 1.0.0 — первый выпуск

- Локальный HTTPS для WPF и API, проверка сертификата, ограничение входа до пяти попыток в минуту.
- Проверка схемы SQLite в /health и отдельное сообщение при тайм-ауте.
- Статистика за один проход с компактной выборкой, CSV с физическими номерами строк, однозначный ввод суммы и даты.
- 52 теста Core, 15 тестов API и 7 тестов WPF. Покрытие строк Core — 88,15 %.
- CI, проверка зависимостей, сценарий сборки, руководство и автономная поставка Windows x64.

## 0.9.0 — альфа-версия

- Шесть модулей решения .NET 10 с запуском окна входа из Visual Studio.
- SQLite с миграциями, семью стартовыми заказами и четырьмя учебными учётными записями.
- Контроллеры заказов, заказчиков и пользователей, Swagger и сценарии HTTP.
- Доступ по JWT для администратора, менеджера и сборщика. Сборщик видит свои заказы.
- Поиск, фильтры, статистика, отчёт ошибок CSV и выгрузка в CSV, JSON, XML.
- Журнал API на Serilog и ежедневный журнал WPF с хранением 14 дней.
