# Мебельная мастерская

Учебная практика УП.02, вариант 13. Автор — Ключков Д. Е., группа 23-СП-9.

Приложение ведёт заказы от замера до установки. Менеджер и администратор ведут заказы и заказчиков. Сборщик видит свои назначенные заказы.

## Запуск

1. Установить Visual Studio 2026 с поддержкой .NET 10 и WPF.
2. Открыть `FurnitureWorkshop.slnx`, выбрать профиль «Мебельная мастерская», нажать F5.
3. Войти под выданной учебной учётной записью. Логины — `admin`, `manager`, `ivan`, `pavel`. Пароли выдаются отдельно.
4. SQLite создаётся в `%LOCALAPPDATA%/FurnitureWorkshop`. При необходимости API можно запустить отдельно с профилем `Local` и открыть Swagger по адресу `http://127.0.0.1:5130/swagger`.

При текущем запуске WPF открывает окно входа и поднимает API на локальном интерфейсе. На чистой базе есть учебные пользователи. Заказы можно создать через интерфейс.

## Локальная проверка

Для запуска интеграционных и оконных тестов или `Smoke-Api.ps1` установите в текущем сеансе PowerShell переменные `WORKSHOP_DEMO_ADMIN_PASSWORD`, `WORKSHOP_DEMO_MANAGER_PASSWORD`, `WORKSHOP_DEMO_IVAN_PASSWORD` и `WORKSHOP_DEMO_PAVEL_PASSWORD`. Передайте соответствующие пароли учебной базы. Для UI-тестов нужен доступ к интерактивному рабочему столу Windows.
