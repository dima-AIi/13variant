# Производительность

Отдельный [проект измерений](../tools/FurnitureWorkshop.Benchmarks) создаёт временную SQLite и 10 000 вымышленных заказов. На каждом сценарии восемь прогревов и 31 измерение. Приведены медианы Release на Windows x64 и .NET 10. Память — выделения текущего потока. Показатели запросов включают чтение и преобразование строк, без сетевого обмена. Перед измерением сверяются итоговые показатели двух реализаций.

| Сценарий | До, мс | После, мс | До, байт | После, байт |
|---|---:|---:|---:|---:|
| Сводка в Core | 0,989 | 0,218 | 27 968 | 624 |
| Чтение SQLite для статистики | 108,793 | 40,193 | 12 306 648 | 4 916 880 |

Для рабочего запроса первое изменение заменяет повторные обходы на накопление по статусам за один проход. Второе читает статус, сумму и две даты вместо карточек с текстами и связями. На измерении сравнивались те же наборы заказов. Новая миграция для этой оптимизации не требуется, существующие индексы выборки остаются в силе.
