# Сценарии WPF

Откройте `FurnitureWorkshop.slnx`, выберите профиль запуска «Мебельная мастерская» и нажмите F5. Откроется окно входа. Клиент запускает локальный API автоматически.

| Роль | Действие | Ожидаемый результат | Проверка |
|---|---|---|---|
| Любая | Вход и выход | Видны имя и роль, после выхода снова открывается вход | UI-автоматизация четырёх учётных записей |
| Любая | Неверный пароль | Окно входа остаётся открытым, выводится ошибка | UI-автоматизация |
| Администратор | Открыть «Пользователи» | Видны четыре учебные записи | UI-автоматизация видимости, проверка API списка |
| Менеджер | Ввести «кухня», выбрать «Установлен», нажать «Найти / обновить» | Таблица содержит только подходящие заказы | UI-автоматизация наличия элементов, проверка результата через API |
| Менеджер | Открыть «Новый заказ» и «Добавить» в заказчиках | Два диалога с подписанными полями и проверкой ввода | Правила и сохранение проверены через API |
| Менеджер | Импортировать тестовый CSV из docs/examples | В диалоге указаны строки 4, 6 и 8. Заказчики не добавлены | Проверка отчёта и атомарности через API |
| Сборщик | Открыть таблицу и сменить статус назначенного заказа | Видны свои заказы, доступны допустимые переходы | UI-автоматизация прав, проверка переходов через API |
| Менеджер | Выгрузить выборку в CSV, JSON и XML | Во всех форматах один и тот же набор заказов | Содержимое файлов проверено через API |

Основные идентификаторы: `OrderSearchInput`, `OrderStatusFilter`, `OrdersGrid`, `NewOrderButton`, `NewCustomerButton`, `FormSaveButton`, `NextStatusSelect`, `ImportButton`, `ImportErrorReport`, `ExportCSVButton` и `LogoutButton`. Формы используют отдельные идентификаторы полей, а системные диалоги открытия и сохранения файлов используют идентификаторы Windows.
