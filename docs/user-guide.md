# Мебельная мастерская. Руководство пользователя

## Запуск

В автономном выпуске Windows x64 распакуйте архив в обычную папку и откройте `FurnitureWorkshop.Desktop.exe`. В режиме разработки откройте `FurnitureWorkshop.slnx` в Visual Studio и запустите профиль «Мебельная мастерская». Окно входа запускает сервер автоматически. База и журналы находятся в `%LOCALAPPDATA%\FurnitureWorkshop`. При первом запуске создаются учебные записи.

## Действия

1. Войдите с учебной учётной записью из материалов практики. Логины: `admin`, `manager`, `ivan`, `pavel`.
2. Менеджер и администратор видят заказы и справочник. Администратору доступна вкладка «Пользователи». Сборщик работает со своими заказами.
3. Создайте заказчика и заказ. Введите стоимость без разделителей тысяч, например `18500,50`. Доставка задаётся в формате `ДД.ММ.ГГГГ`, также принимается `ГГГГ-ММ-ДД`.
4. Заказ проходит стадии «Замер», «Проект», «Изготовление», «Доставка», «Установлен». Перед изготовлением назначьте сборщика, перед установкой заполните сумму и дату доставки. При отмене укажите причину.
5. Для поиска введите часть изделия, адреса, имени заказчика, телефона или номер. Для отбора выберите статус и нажмите «Найти / обновить». Enter в поле поиска запускает поиск.
6. Импорт принимает CSV в UTF-8 с заголовком `Name,Phone,Email`. При ошибке откройте список строк, исправьте файл и повторите импорт. Для выгрузки нажмите CSV, JSON или XML. При открытии CSV в Excel можно указать UTF-8 и разделитель «точка с запятой» через «Из текста/CSV».
7. Вкладка «Статистика» показывает количество заказов по статусам, суммы и средний срок завершения. Для смены аккаунта нажмите «Выйти».

## Самостоятельный API

Для отдельного API установите доверенный локальный сертификат командой `dotnet dev-certs https --trust`, затем запустите проект Api с профилем Local. Swagger доступен на `https://localhost:7130/swagger` в Development. Для повседневной работы WPF достаточно запуска приложения. Дополнительная установка сертификата для встроенного API не требуется.
