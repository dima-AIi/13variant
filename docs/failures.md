# Диагностика сбоев

Испытывались временные базы, свободные локальные порты и тестовые сертификаты. Рабочая база оставалась доступна своему экземпляру программы.

| Сценарий | Воспроизведение | Результат |
|---|---|---|
| Остановленный сервер | HTTPS-запрос на освобождённый порт | Соединение отклонено; WPF обрабатывает HttpRequestException |
| Занятый порт | Тестовый сокет слушает порт до запуска API | Второй процесс не стартовал; в диагностике ошибка привязки |
| Ошибка пути SQLite | Путь файла указан на существующий каталог | Запуск остановлен, SQLite 14 |
| Ошибка конфигурации | `Jwt__Key` из 3 байтов | Сервер отклонил запуск с сообщением про Jwt:Key |
| Тайм-аут | Тестовый сокет принял подключение и не завершил TLS | Клиент достиг заданного тайм-аута; WPF показывает своё сообщение |
| Пропавшая таблица | В тестовой БД после старта удалена таблица Orders | 0.9.0 возвращала 200; 1.0.0 вернула 503 без SQL-деталей |

## Дефекты

- Проверка доступности базы не выявляла потерю таблицы. Исправлена проверкой запроса к таблице заказов.
- Пустая строка перед заголовком CSV ломала выбор разделителя. Исправлен выбор первой непустой строки, номер ошибки соответствует физической строке файла.
- Три цифры после запятой трактовались как дробная часть суммы, например `1,500` могло означать 1,50. Теперь такой ввод явно отклоняется.

## Отладка статистики

Проверяются начальная и конечная записи последовательности, условие учёта установленных заказов и точность денежных сумм. Пересчёт отрицательного срока воспроизведён с датой установки раньше создания и исправлен. Модуль выводит общее число, распределение, количество в работе, количество завершённых и отменённых, общую сумму, сумму установленных и средний срок. Нулевая выборка возвращает пустой средний срок.

Для показа в Visual Studio установите точку останова в `OrderRules.StatisticsFromMetrics` и посмотрите `row.Status`, `counts`, `durationCount` и `duration`. Тесты воспроизводят данные последовательно. Для отладки переходов используются DebuggerDisplay и два Debug.Assert. Debug.WriteLine отмечает время выгрузки CSV, JSON или XML; трасса предназначена для Debug, рабочие журналы приложения доступны в обеих конфигурациях.
