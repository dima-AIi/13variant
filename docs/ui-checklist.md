# Проверка WPF

| Сценарий | Результат и источник |
|---|---|
| Вход администратора и меню пользователей | Пройдено в FlaUI |
| Вход менеджера и доступ к справочнику | Пройдено в FlaUI |
| Вход Ивана и Павла, команды менеджера скрыты | Пройдено в FlaUI |
| Неверный пароль, ошибка в окне входа | Пройдено в FlaUI |
| Выход, пустой логин в вновь открывшемся окне | Пройдено в FlaUI для всех четырёх аккаунтов |
| Смена количества строк после поиска «КУХНЯ» | Пройдено в FlaUI, семь → одна |
| Фильтр «Установлен» | Пройдено в FlaUI, семь → две |
| Идентификаторы поиска, фильтра, кнопок и полей | Проверены разметка и выборка элементов FlaUI |
| Ввод суммы с точкой и запятой | Проверено общим правилом формы и Core-тестами |
| Неоднозначная сумма и неверная дата | Отклонены в тестах правил ввода |
| Пустая выдача поиска не вызывает исключений | Проверено API и привязкой пустого массива WPF |
| Терминальный заказ | Кнопка смены статуса недоступна; правило проверено Core-тестами |
| Очистка клиентского журнала старше 14 дней | Пройдено в FlaUI |
| Потеря связи и задержка | См. [диагностику](failures.md); сообщения клиента проверены в коде обработки |
| Enter в поиске и диалогах, Esc в диалогах | Команды и свойства проверены в XAML и коде форм |
| Порядок Tab и отсутствие обрезания при 125 % | Отдельная ручная проверка при таком масштабе не проводилась |

Проверки, характерные для мастерской: разные права Ивана и Павла, поиск кириллицей, фильтр «Установлен», ввод суммы и даты доставки. Программный чек-лист и подтверждающие тесты дополняют визуальный просмотр на защите.
