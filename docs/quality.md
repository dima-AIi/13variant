Покрытие получено сборщиком Coverlet в прогоне xUnit Core/API. Включены анализаторы SDK и правила CA2016 и CA2022 в `.editorconfig`. Эти правила проверяют передачу токена отмены и корректность чтения потока. Список предупреждений по включённым правилам пуст. Отдельных подавлений в конфигурации проекта нет.

Прогон разработчика выполняется через `build.ps1`. В GitHub Actions публикуются сводка тестов и Cobertura. Тесты FlaUI запускаются отдельно на интерактивном рабочем столе Windows с учебными аккаунтами.
