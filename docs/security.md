# Проверка безопасности

| Угроза | Реализация и проверка |
|---|---|
| Перехват пароля и JWT | WPF и API используют HTTPS на loopback. Внешний конфиг с HTTP отклоняется. |
| Подмена локального сервера | WPF принимает сертификат своего экземпляра по SHA-256 и ожидает адрес 127.0.0.1. Доверие Windows не расширяется. |
| Публикация ключа подписи | Встроенный сервер создаёт случайный ключ при запуске. Отдельный Development API читает опциональный `Jwt:Key` из User Secrets. Ключ длиной 3 байта отклоняется. |
| Перебор пароля | Пять входов в минуту на IP-адрес, шестой запрос получает 429. |
| Компрометация файла БД | Учётные записи хранят соль и PBKDF2-SHA256. API каталога пользователей не возвращает хешей. |
| Запрос без прав | Отсутствующий или отозванный JWT даёт 401, запрещённая роль — 403. |
| Чужой заказ | Фильтр сборщика выполняется в запросе к БД. Чужая карточка и переход дают 404. |
| Инъекции в поиске | EF Core параметризует поиск. Кавычки и символы подстановки не расширяют результаты. |
| Утечка через ошибки и журналы | Ответ 503 скрывает исключение SQLite. В журналах проверено отсутствие паролей и JWT. |
| Формулы в CSV | Текстовые ячейки с начальным `=`, `+`, `-` или `@` защищены апострофом. |
| Сбой из-за чрезмерного CSV | Лимиты 1 МиБ и 5 000 строк. При ошибках нет частичной записи. |
| Уязвимости зависимостей | NuGet Audit проверяет прямые и транзитивные зависимости. NU1903 и NU1904 считаются ошибками сборки. |

## Ключ для отдельного API

Из папки решения, при запуске профиля Local:

```powershell
dotnet user-secrets set 'Jwt:Key' ([Convert]::ToHexString([Security.Cryptography.RandomNumberGenerator]::GetBytes(32))) --project FurnitureWorkshop.Api
```

Повтор команды и перезапуск заменяют ключ. Сеансы, подписанные предыдущим ключом, теряют силу. Встроенный API создаёт ключ в процессе и выпускает новые токены после перезапуска. User Secrets подходят для разработки на одном компьютере.

Учебные аккаунты имеют известные участникам демонстрационные пароли. Поставка рассчитана на локальную демонстрацию, а не на открытый сервер с реальными клиентскими данными.
