## Переходы

| Текущий статус | Следующая рабочая стадия | Условие |
|---|---|---|
| Замер | Проект | Последовательный переход |
| Проект | Изготовление | Назначен сборщик |
| Изготовление | Доставка | Последовательный переход |
| Доставка | Установлен | Заполнены дата доставки и положительная сумма |
| Любая рабочая стадия | Отменён | Указана причина |
| Установлен или Отменён | — | Переходы закрыты |

## Приёмочные сценарии

1. **Дано** менеджер вошёл и выбрал заказчика. **Когда** создаёт заказ и назначает Ивана. **Тогда** заказ начинается с замера и доступен Ивану. Проверки Т06–Т07.
2. **Дано** заказ в доставке. **Когда** сборщик пытается установить его без даты или суммы. **Тогда** API отвечает 400. После внесения реквизитов переход проходит. Проверки Т09 и этап установки в Smoke-Api.
3. **Дано** CSV из десяти записей с ошибками. **Когда** менеджер отправляет файл. **Тогда** сервер возвращает номера ошибочных строк и сохраняет исходное состояние справочника. Проверка Т15 и `wrong_csv` в requests.http.
