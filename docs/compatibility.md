# Совместимость

| № | Конфигурация | Проверка и результат |
|---:|---|---|
| 1 | Windows x64, .NET 10, Debug | Шесть проектов собраны. Строка отладочного замера присутствует в сборке. |
| 2 | Windows x64, .NET 10, Release | Семь UI-сценариев. Строка Debug.WriteLine отсутствует. |
| 3 | Windows x64, зависимая публикация | Запуск подтверждён тестом формы входа. Требуются .NET Desktop Runtime и ASP.NET Core Runtime 10. |
| 4 | Windows x64, автономная публикация | Средства выполнения входят в поставку. Программа запускается из папки публикации. |
| 5 | ru-RU | Ввод `1500,50` и `1500.50` возвращает одну сумму. |
| 6 | en-US | Форматы с одной десятичной точкой или запятой дают ту же сумму. |
| 7 | de-DE | Десятичная запятая сохраняет значение суммы. |
| 8 | Кириллический путь и UTF-8 | Сборка и запуск из каталога «вариант13», кириллица в поиске, импорте и выгрузках. |
| 9 | JSON, XML и CSV | Проверено совпадение набора строк. Даты выгрузок проверены с зоной UTC. |

Доставка принимается как `ДД.ММ.ГГГГ` или `ГГГГ-ММ-ДД`; двусмысленная запись через косую черту отклоняется. Исправлен случай `1,500`, который раньше означал 1,50 рубля. Для Excel с другой настройкой разделителей используйте импорт через «Из текста/CSV», UTF-8, точка с запятой. Отдельная физическая машина без среды выполнения и масштаб 125 % не входили в проверенное окружение.

Сравнение файлов публикации до упаковки: зависимая — 43 442 891 байт, автономная без объединения файлов — 185 219 993 байт. Выпуск включает автономный архив.
